MINIHESAP - ON MUHASEBE ISKELETI

Dosyalar:
- app/on-muhasebe/page.tsx
- components/OnMuhasebeDemo.tsx
- app/private/products/MiniHesap_On_Muhasebe_Takip.xlsx

Kurulum:
1. Bu klasörlerdeki dosyaları mevcut mini-hesap projenizin aynı konumlarına kopyalayın.
2. Mevcut dosyaların üzerine yazmadan önce yedek alın.
3. Terminalde npm run build çalıştırın.
4. Local test: http://localhost:3000/on-muhasebe

Not:
- Bu paket mevcut projenin tamamını içermez; yalnızca Ön Muhasebe özelliğinin eklenmesi için gerekli iskelettir.
- Mevcut Borç Takip, API ve diğer dosyalara dokunmaz.
