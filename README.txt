MiniHesap reklam altyapısı iskeleti.

Dosyalar:
components/AdBanner.tsx
components/AdSlot.tsx

Mevcut MiniHesap projesindeki components klasörüyle birleştirin.

Kullanım:
import AdSlot from "@/components/AdSlot";

<AdSlot position="top" />
<AdSlot position="middle" />
<AdSlot position="bottom" />

Şimdilik gerçek reklam kodu yoktur. Reklam ağı bağlandığında merkezi olarak değiştirilebilir.
