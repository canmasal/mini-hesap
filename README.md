# MiniHesap — Temiz Başlangıç

Bu proje kök dizinde `app`, `components`, `data`, `lib` ve `public` klasörleriyle hazırlanmıştır.

## Kurulum

1. `mini-hesap` klasörünü VS Code ile aç.
2. Terminalde:
   `npm install`
3. Sonra:
   `npm run dev`
4. Tarayıcı:
   `http://localhost:3000`

ÖNEMLİ:
- `package.json` doğrudan projenin kökünde olmalıdır.
- `lib` klasörü `app` ile aynı seviyededir.
- `node_modules` elle taşınmaz; `npm install` ile oluşturulur.
- Bu sürüm Tailwind kullanmaz.
